The downloadable derived database contains projected coordinates, source way
and node identifiers, the bounding box, query, source snapshot timestamp,
selected tags and the widths adapted for the game. Rebuild with
scripts/import_rome_taxi.py. No OpenStreetMap tile images are downloaded.

Road widths, signal phase timings and stop-line setbacks, destinations,
buildings' illustrated materials and driving rules are game adaptations.
Traffic-signal source nodes and building footprints are retained from OSM;
mapped building heights/levels are used where present, with illustrated
defaults otherwise. This is not a navigation application.
The building, vehicle and character artwork is separate from this database.
